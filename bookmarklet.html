📌 How to install:
  1. Make sure your bookmarks bar is visible (Ctrl/Cmd + Shift + B)
  2. Drag the "🛡️ XSS Guardian" button above to your bookmarks bar
  3. Navigate to any website you want to scan
  4. Click the bookmarklet in your bookmarks bar
  5. View results in the browser console (F12)

Manual Loading via Console

You can also load XSS Guardian directly in the browser console. Open the developer tools (F12) and paste this code:

var script = document.createElement('script'); script.src = 'https://cdn.jsdelivr.net/gh/yourusername/xss-guardian@main/dist/xss-guardian.js'; script.onload = function() { console.log('XSS Guardian loaded!'); XSSGuardian.quickScan(); }; document.head.appendChild(script);

Usage Examples

Quick Scan (Recommended)

// Run a quick scan const result = await XSSGuardian.quickScan();

Deep Scan (with mutation testing)

// Run a comprehensive deep scan const result = await XSSGuardian.deepScan();

Custom Scan

// Custom scan with specific options const result = await XSSGuardian.scan({ depth: 20, includeShadowDOM: true, includeIframes: true, mutationTest: false, payloadComplexity: 'advanced', verbose: true });

Export Report

// Export as HTML XSSGuardian.exportReport(result, 'html'); // Export as JSON XSSGuardian.exportReport(result, 'json');

Key Features

🔍 DOM Analysis

Deep inspection of DOM structure, attributes, and event handlers to detect XSS vectors

🎯 Framework Detection

Specialized analyzers for Aurelia, React, Vue, Angular, Alpine.js, and more

🧪 Mutation Testing

Active testing with payload injection to find reflected and DOM-based XSS

💉 Comprehensive Payloads

Extensive payload library with encoding, obfuscation, and WAF bypass techniques

📊 Visual Reports

Beautiful console output with color-coded severity levels and detailed findings

💡 Remediation Advice

Specific, actionable recommendations for fixing each vulnerability

🌐 Shadow DOM Support

Scans inside Shadow DOM and web components

📥 Export Options

Export reports as HTML or JSON for documentation and tracking

NPM Installation

For integration into your development workflow:

npm install xss-guardian

Then in your code:

import XSSGuardian from 'xss-guardian'; // Run scan const guardian = XSSGuardian.create(); const result = await guardian.scan();
